# Video Dialogue Translator

Phần mềm / trang web: dán đường link video vào -> tự tạo khung lời thoại kèm bản dịch.

## Ý tưởng chức năng (đang thảo luận)
- Nhập 1 hoặc nhiều link video
- Lấy / nhận diện lời thoại trong video (transcript)
- Hiển thị thành khung lời thoại theo từng câu / từng đoạn, kèm bản dịch
- Chi tiết định dạng khung, ngôn ngữ nguồn/đích, nền tảng video hỗ trợ: đang chốt trong quá trình thảo luận
